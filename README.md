# Python Programming Projects

## Introduction
This repository contains my Python programming practice work. It includes five programs based on different programming concepts.

## Programs Included
1. **Student Result Management System** — stores student details and calculates marks, percentages, and grades.
2. **Word Analysis** — analyzes a sentence by counting words, characters, and vowels.
3. **Product Billing System** — calculates product costs and the final bill.
4. **Calculator** — performs basic mathematical operations.
5. **Restaurant Menu and Billing** — takes food orders and calculates the bill.

## Language and Tools
- Python
- Jupyter Notebook
- GitHub

## How to Run
1. Download or clone this repository.
2. Open the `.ipynb` file in Jupyter Notebook.
3. Run the code cells one by one.

## Purpose
The purpose of this project is to practise Python programming and understand how functions, loops, dictionaries, conditional statements, and file handling work.
